# Block consolidation — 45 layout blocks to 13

Decided 2026-09-24 (Kenn). ADR: [`0013-thirteen-blocks.md`](../decisions/0013-thirteen-blocks.md).

**Done when** every current page, plus any ordinary new page, composes from these blocks in the content JSON with no
code change. The new-page test is three market pages: Oklahoma City, Kansas City, Austin.

## Rules

- **No numeric caps.** No `maxRows`, `maxLength` or `max`; no `minRows` above 1. A layout that degrades past N items
  handles N. Gate: `tests/int/blocks/noCaps.int.spec.ts`.
- **The block list is pinned.** Gate: `tests/int/blocks/allowedBlocks.int.spec.ts`. Adding a block edits that list and
  needs Kenn's sign-off. A new look is an option on an existing block.
- **Shared fields.** Every block except `hero` takes `background` (`none | subtle | accent | inverse`). Blocks that
  hold several items take `heading` and `intro`.
- Every control changes the output (`blockOutputContract.int.spec.tsx`, INERT-2 — unchanged).

## Migration

The content JSON is the source of truth. A one-off script rewrites every `layout` onto the new blocks, and each
environment rebuilds from the JSON. The Payload migration drops the old block tables; it carries no data transform.
